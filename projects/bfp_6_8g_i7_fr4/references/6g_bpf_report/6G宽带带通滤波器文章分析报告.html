核心判断：这是一个“高选择性、小型化”的 6GHz 以上 BPF 参考方案
文章围绕四阶宽带带通滤波器，使用折叠 SIR 与混合电磁交叉耦合生成多个传输零点。
6.8GHz滤波器中心频率，目标面向 6G / 卫星通信射频前端。
22.8%实测相对带宽，属于较宽带带通设计。
1.39dB中心频率插入损耗，依赖 Rogers 4003C 等低损耗材料。
4 TZ通过混合电磁效应与交叉耦合形成 4 个传输零点。
文章价值
  • 给出可落地的宽带 BPF 架构，而不是单纯理论耦合矩阵。
  • 传输零点来源清晰：外部混合电磁耦合 + 谐振器间交叉耦合。
  • 尺寸和实测指标适合作为 6-8GHz 小型化方案 benchmark。
直接限制
  • 文章目标中心频率为 6.8GHz，带宽覆盖不一定完整等同 6-8GHz。
  • 材料为 Rogers 4003C，不能直接迁移到 FR4 低成本板。
  • 缺少完整几何尺寸表和 EM 设置细节，复现需重新参数化。
对当前任务的意义
  • 可作为当前 ADS 自动化流程的新结构候选。
  • 优先借鉴“可调 TZ + 双模谐振器”的设计方法。
  • 建议先做结构复现，再与交指 / stub / high-low SIR 对比。
建议结论：不要直接照搬尺寸；应抽象为新的参数化候选结构并纳入 ADS/FEM 扫描。

技术拆解
GTS
结构逻辑：折叠 SIR 提供小型化，混合耦合负责零点与选择性
文章方案不是单一路径耦合，而是通过多路径组合控制带外响应。
1四阶拓扑第一、四阶为单模谐振器；第二、三阶为双模谐振器。
2折叠 SIR折叠阶跃阻抗谐振器缩短物理长度，兼顾谐振频率与面积。
3双模控制双模谐振器偶模约 6.37GHz，奇模约 7.3GHz。
4交叉耦合第一与第四阶谐振器间形成额外耦合路径，产生 TZ2/TZ3。
5混合电磁通过电耦合 / 磁耦合比例移动传输零点，改善带外抑制。
设计对象文章中的作用调参含义工程关注点
馈线间距 t1控制外部品质因素 Qe，影响端口耦合强度。间距增大，Qe 增大，外部耦合减弱。匹配
谐振器间距 / 孔径调节磁耦合 Mij 与电耦合 Eij 的比例。改变传输零点位置和带外陡峭度。选择性
双模 SIR 参数分别约束偶模、奇模谐振点。决定通带内部极点分布和带宽。带宽
折叠布局降低面积，同时引入邻近耦合可能性。必须通过 EM 仿真校正寄生耦合。EM 依赖
工程理解：该方案的关键不在“某一组尺寸”，而在“可独立调节外部耦合、主耦合、交叉耦合和混合电磁耦合”的自由度。

参数版图对应位置调参机理对曲线的预期影响
t1馈线与下方谐振器之间的间距控制外部品质因素 Qe。文章图 3.2(a)显示 t1 增大时 Qe 增大，说明外部耦合变弱。t1 过小：插损低但回波变差；t1 过大：耦合不足、通带塌陷。
S上/下谐振器之间的主要耦合间距图 3.2(b)显示 S 改变 k12/k14。S 增大通常降低近场耦合，影响主通带耦合和交叉耦合平衡。改变通带宽度、纹波和 TZ 位置，属于最敏感 sweep 项之一。
d1右下方 via / 谐振器局部加载位置图 3.5(a)显示 d1 改变时 TZ3、TZ4 位置移动。它更像调混合电磁耦合的局部电长度和场分布。主要移动高频侧零点，也会牵动 8GHz 边缘插损。
d2橙色折叠臂末端与局部耦合区域的横向距离图 3.2(c)显示 d2 增大时 k23 降低。它是双模/相邻谐振器耦合强度调节项。d2 增大：耦合减弱，带宽收窄；d2 减小：带宽扩大但纹波和寄生耦合风险上升。
W1/W2/L1-L4紫色 U 形和橙色折叠段的线宽/长度决定阻抗阶跃比与等效电长度。文章给出的 Z1/Z2/Z3、θ1/θ2/θ3 本质上要通过这些几何尺寸实现。影响中心频率、偶/奇模分裂、寄生通带位置。

公式细读 1

式 3.1 / 3.2：双模 SIR 的偶模与奇模约束
这两条公式不是评分公式，而是把目标谐振频率反推到阻抗阶跃和电长度的综合约束。
Z2(Z1 - 2Z3 tanθ1 tanθ3) - Z1 tanθ2(Z1 tanθ1 + 2Z3 tanθ3) = 0
式 3.1 对应偶模条件。由于偶模面等效边界改变，Z3、θ3 的加载项进入公式，因此它对短路/开路加载、折叠末端和 via 等寄生更敏感。
Z2 - Z1 tanθ1 tanθ2 = 0
式 3.2 对应奇模条件。它形式更简单，主要由 Z1、Z2 及 θ1、θ2 决定。文章用它把奇模设在约 7.3GHz。
变量工程解释版图落点
Z1/Z2/Z3不同线宽微带段的特性阻抗，文章给出 111.6Ω / 76.8Ω / 101.5Ω。W1/W2/W3 线宽
θ1/θ2/θ3各段在目标频点的电长度，文章给出 34.9° / 44.9° / 1.3°。L1/L2/L3 或折叠段
偶模 6.37GHz低侧极点，决定 6GHz 附近边缘支撑。双模谐振器整体加载
奇模 7.3GHz高侧极点，决定 8GHz 附近边缘支撑。双模谐振器线宽/长度

公式细读 2
GTS
式 3.3：外部品质因素 Qe 是端口耦合强弱的量化入口
当前 ADS 自动化里 tap_mm / feed_gap_mm 的扫描，本质上也在调 Qe。
Qe = 2π · f0 · τ(f0) / 4
这里 τ(f0) 是中心频率处群时延。Qe 越大，外部耦合越弱；Qe 越小，外部耦合越强。文章通过 t1 控制 Qe。
现象解释对 ADS sweep 的启发
t1 增大，Qe 增大馈线与谐振器距离变远，端口注入能量变少。feed_gap_mm 需要单变量扫。
Qe 过小过耦合，通带可能更宽但回波恶化，插损和纹波不稳定。评分需加入 worst S11/S22。
Qe 过大欠耦合，带内能量进不去，通带边缘下陷。关注 S21@6G / S21@8G。
群时延法从单谐振器仿真提取 Qe，比直接全结构扫更可解释。可新增 prepare 单腔仿真模式。
公式结论：文章用 Qe 把“馈线离多远合适”从经验版图问题变成可提取指标。当前流程若新增该结构，应先扫单谐振器 Qe，再进入完整滤波器 FEM。

公式细读 3
GTS
式 3.8：传输零点由磁耦合 Mij 与电耦合 Eij 的比值控制
这是文章最值得迁移的核心：零点位置不只靠阶数，而靠电/磁耦合比例。
fTZ = f0 √(Mij / Eij)
当 Mij / Eij 增大，传输零点向高频移动；当比值减小，零点向低频移动。实际版图中 Mij 与 Eij 不是孤立元件，而由缝隙、重叠长度、接地 via、电流方向共同决定。
图 3.5 观察技术解释工程判断
d1 改变TZ3/TZ4 明显移动，说明 d1 对混合电磁耦合比值敏感。d1 应作为高频零点控制旋钮，不宜和长度 L 同时大步扫。
S2 改变TZ1/TZ2/TZ3 的相对位置和深度变化，说明 S2 同时影响多个耦合路径。S2 是多目标变量，需小步长 sweep 并记录零点位置。
零点深度变化某些曲线零点变浅，代表电/磁抵消条件偏离。评分不能只看频点衰减，还要看零点是否稳定。
上阻带抑制高频侧 TZ 位置影响 9-16GHz 抑制包络。当前 4-10GHz 仿真可能不够，应扩到 16GHz 做杂散检查。

耦合矩阵与实测偏差
GTS
矩阵说明设计目标，实测图暴露制造与过渡结构误差
图 3.3/3.6 需要一起看：理想耦合矩阵能产生深零点，但实物会出现零点变浅和频率偏移。
观察点细节解读对复现的要求
矩阵 S-1 / 4-L 为 0.8905源到 1、4 到负载的外部耦合对称，说明版图左右镜像是为了保证输入输出匹配一致。生成器必须保持左右端口和谐振器对称，除非刻意做补偿。
M12/M34 = 0.7728主耦合强，支撑宽带通带；若该值不足，6/8GHz 边缘会下陷。主间隙 S/d2 要优先校准。
M14 = -0.1254负号代表交叉耦合极性相反，是产生有限频率传输零点的关键。版图交叉路径不能简化掉。
仿真/实测曲线差异实测曲线零点不如仿真深，带外包络也有偏差，常见来源是 SMA 焊接、铜粗糙度、介电常数偏差和 via 寄生。ADS 模型需加入端口过渡余量，并做材料参数敏感性。
