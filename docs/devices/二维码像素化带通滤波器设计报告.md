本文档用于建立 6-8 GHz 二维码式像素化带通滤波器分支。这里的“二维码滤波器”不是 ISO QR 编码器件，而是将耦合区域离散为 0/1 金属像素矩阵的微带滤波器。其本质属于 pixelated / binary-coded / inverse-designed microstrip filter。

## 1. 文献归纳

公开资料中更常见的关键词如下：

| 方向 | 可检索关键词 | 对本分支的意义 |
|---|---|---|
| 像素化滤波器 | `pixelated microwave filter`, `pixelated bandpass filter` | 将金属区域离散为小单元，通过二值拓扑改变耦合路径和寄生谐振。 |
| 二值编码结构 | `binary-coded microstrip`, `binary pixel resonator` | 适合用 0/1 参数表驱动版图生成和自动优化。 |
| 逆向设计 | `inverse-designed microstrip filter`, `direct binary search` | 可使用 DBS、GA、贝叶斯优化或代理模型逐步逼近目标 S 参数。 |
| QR-like 电磁结构 | `QR-code-like electromagnetic structure` | 图案外观类似二维码，但评价标准是 EM 响应，不是码字可读性。 |

文献共性结论：

- 像素化拓扑通常不能只靠闭式公式一次定型，需要全波 EM 仿真闭环。
- 像素开关会同时改变有效电长度、耦合强度、寄生零点和局部电流回流路径。
- 直接二值搜索适合早期探索，但变量数随矩阵阶数快速增加；8x8 已有 64 个二值变量，10x10 有 100 个二值变量。
- 对称约束可显著降低搜索空间，并让两端口结构更易保持互易和端口匹配。
- FR4 在 6-8 GHz 损耗和介电常数离散性较明显，因此最终必须做材料容差和加工容差复测。

本次检索到的关键参考：

| 资料 | 结论摘录 |

## 2. 设计目标

| 项目 | 初始值 |
|---|---|
| 材料 | FR4 |
| 介质厚度 | 0.210 mm |
| 铜厚 | 0.035 mm |
| 频段 | R0/R1 为 4-10 GHz 仿真；R2 起扩展为 1-10 GHz 仿真，6-8 GHz 通带 |
| 阻带目标 | 先按 5 GHz 约 20 dB 抑制探索 |
| 最小线宽/间距 | 初版按 4 mil，即 0.1016 mm |
| 端口规则 | P1/P2 位于 50 ohm 输入输出线端点，单位 mm |
| 图层规则 | `cond` 金属，`pcvia1` 过孔，`EM_BOUNDARY` 仿真边界 |

## 3. 初版拓扑

初版采用“二值像素耦合区 + 两侧 50 ohm 馈线”的形式：

```text
P1 feed -> taper/overlap -> binary pixel matrix -> taper/overlap -> P2 feed
```

矩阵规则：

- 8x8 和 10x10 两个尺寸同时生成。
- 像素单元按二维码模块方式铺设；相邻黑色像素共边贴合，形成连续铜皮，不使用额外补桥图形。
- 白色像素为空窗；非相邻铜岛之间的间距由一个或多个白色像素宽度决定。
- 默认使用左右镜像对称 mask，降低变量维度。
- 边缘行/列保留部分连续金属，保证输入输出有明确耦合路径。
- 孤立金属岛允许作为初始探索，但后续优化应记录 island 数量，并优先保留与主耦合路径相关的金属。

## 5. 参数影响

| 参数 | 增大后的主要影响 | 优化方向 |
|---|---|---|
| 像素尺寸 | 等效电长度和电容加载增大，中心频率倾向降低。 | 如果通带偏高，可增大像素或增加连通路径。 |
| 白色像素开窗 | 金属连通路径减少，低频直通减弱，阻带零点更容易出现；过多开窗会导致耦合不足。 | 初期通过 mask 控制开窗分布，不再用补桥修正相邻黑色像素。 |
| 矩阵高度 | 横向寄生路径增多，零点和阻带形状更复杂。 | 8x8 用于快速探索，10x10 用于细调零点。 |
| 馈线重叠 | 输入输出耦合增强，回损和带宽会明显变化。 | 回损差或带宽窄时优先扫描该参数。 |
| 对称 mask | 响应更稳定，变量少。 | 初期保持对称，后期再开放局部非对称。 |
| 金属填充率 | 过高接近宽线/低通，过低耦合不足。 | 初始填充率建议 35%-60%。 |

## 6. 优化路线

推荐分三阶段：

| 阶段 | 方法 | 目标 |
|---|---|---|
| R0 | 生成规则 mask：checker、diag、qr_seed、edge_coupled、symmetric_random | 找到能形成 6-8 GHz 带通雏形的拓扑族。 |
| R1 | 固定 mask，扫描 feed overlap、pixel、gap、feed_w | 修正中心频率、带宽和端口匹配。 |
| R2 | 在最好 R1 附近做二值翻转 DBS/GA | 拉深 5 GHz 抑制，补充传输零点，降低通带插损。 |

评分建议：

```text
硬约束：min(S21 6-8GHz) > -6 dB，S21@5GHz < -20 dB。
软目标：提升通带最小 S21，降低通带纹波，改善 S11/S22。
惩罚项：违反最小间距、过多孤岛、端口未落在金属上、边界不足。
```

## 7. 可制造性

FR4 210um、4 mil 间距对 6-8 GHz 像素化结构可做初版验证，但需要注意：

- 像素间隙不要低于 0.1016 mm。
- 过多小孤岛会增加蚀刻偏差和 EM 网格敏感性，后续应统计孤岛数量。
- 50R 线宽必须用实际层叠重新校准；当前 0.36 mm 只是可生成初始值。
- FR4 的介电常数和损耗批次离散会带来中心频率和插损漂移，报告结论必须以 EMSETUP/FEM 结果为准。

## 9. 当前阶段总结

二维码像素化带通滤波器分支已经完成从概念验证到 ADS/RFPro 自动仿真的初步闭环。当前分支采用 FR4、0.210 mm 介质厚度、35 um 铜厚、L1 参考地，目标频段为 6-8 GHz；R0/R1 仿真频段为 4-10 GHz，R2 架构探索已扩展为 1-10 GHz。版图单位统一为 mm，金属层为 `cond`，过孔层为 `pcvia1`，边界层为 `EM_BOUNDARY`，home profile 下 ADS/RFPro setup 固定使用 `BFP_lib:substrate4`，避免误用 RO4350 的 `substrate1`。当前结构不作为标准 QR 码电路处理，而是作为二值像素化微带滤波器处理。0/1 金属矩阵用于改变电流路径、局部耦合、电容加载和传输零点位置。该类结构没有可靠闭式公式，需要依赖全波仿真和参数/拓扑迭代。当前自动化链路已能完成参数表生成、DXF 版图导入、端口放置、EM setup 复制修补、RFPro FEM 仿真、S 参数导出和评分汇总。

## 11. 关键问题判断

当前方向是可行的，但尚未达到可用滤波器指标。主要限制不是版图无法形成带通，而是端口匹配和外部耦合仍然不足。已仿真的 0.30/0.35/0.40 mm 候选中，6-8 GHz 内最差 S11/S22 约为 -0.64 至 -1.93 dB，说明输入输出大部分能量仍被反射，滤波器尚未进入良好匹配状态。下一轮不应只继续扩大或缩小像素尺寸，而应优先调整馈线重叠、馈线宽度、输入输出过渡形状和边缘耦合像素分布。

从频率趋势看，增大像素尺寸会增加等效电长度和加载效应，使结构谐振/零点整体向低频移动；尺寸过大时 6-8 GHz 反而被切成阻带。0.35 mm 是当前比较合适的中间点。5 GHz 抑制仍未达到 20 dB，后续需要通过 mask 局部翻转、引入更强的低频零点路径，或增加接地/短路像素机制来改善低边阻带。

这些参数关系比单个分数更重要：R1 提供的是一个干净的局部响应面。同一 mask/hash、同一 FR4 210um 层叠、同一 16x16 拓扑下，只改变尺寸、overlap 和 feed_w，就能观察中心频率、高边滚降、通带底部和匹配的方向性变化。因此这 8 个 cell 应作为后续 R3/R4 的参数基准库保留。

R1 结论：

- 当前 0.35 mm 单元仍是主窗口；0.32/0.33 mm 会把高边推高，9 GHz 抑制不足。
- `feed_w_mm=0.38`、`coupling_overlap_mm=0.45` 是 R1 中最好的局部组合，但改善幅度很小，最差回损仍只有约 -2 dB。
- 低边 5 GHz 抑制仍约 -6.6 dB，距离 -20 dB 探索目标还有约 13 dB 差距；单纯扫描像素尺寸、馈线宽度和 overlap 不能解决低边零点问题。
- 下一轮不应继续做小步几何扫描，而应进入拓扑机制调整：局部 mask 翻转、边缘耦合像素重排、stub 化路径，或建立接地/短路像素规则来引入低频传输零点。

建议 R2 以 `p035_fw038_ol045` 为几何基准，但不要只围绕 feed 参数微调。R2 首先做小规模二值翻转，每个候选限制翻转 4-12 个像素，评分权重提高 5 GHz 抑制和 6-8 GHz 回损；若仍无法拉深低边阻带，再单独引入短路像素/接地过孔拓扑族。

## 17. R2 结论与下一步模型路线

R2 筛选后，最有价值的方向是 `edge_stubs` 和 `qr_sparse_s1`。它们不是当前 6-8 GHz BPF 的直接答案，而是两个清楚的高边阻带模型：`edge_stubs` 以边缘加载 stub 形成 7 GHz 以上快速衰减，`qr_sparse_s1` 以低填充率稀疏像素形成更强的 8-10 GHz 深阻带。其它架构要么过于宽通、要么偏高通、要么几乎断连，对当前目标贡献不够，已从 R2 活跃数据集中删除。

可复用模型路线如下：

1. 以 `edge_stubs` 为边缘加载母版，扫描 stub 行位置、端部宽度、边缘柱数量和中心横向通道宽度，目标是把高边阻带保持在 8-10G，同时避免 6-7G 过早塌陷。
2. 以 `qr_sparse_s1` 为低填充率母版，扫描填充率 0.36-0.48、seed 和强制边缘耦合规则，目标是找到 6-8G 内仍可传输但 8.5-10G 维持深抑制的稀疏模型。
3. 下一轮需要额外引入低边抑制机制，因为这两个保留模型在 5G 仍接近直通，不能单独形成 6-8G 带通。
4. R3 评分应记录 1-3G、5G、6-8G、8.5-10G 四段平均 S21，并把 7G 以后塌陷位置作为独立特征。

R3 建议围绕 `edge_stubs` 与 `qr_sparse_s1` 做小规模局部变体，不再扩展本轮已删除的其它架构族。

## 18. S21 神经网络代理模型路线

当前神经网络路线已从 S21-only surrogate 升级为 S11/S21/S22 三通道代理模型：输入 16x16 像素矩阵、via 通道和几何标量，输出 1-10 GHz 采样点上的 S11/S21/S22(dB)。反馈仍以 S21 曲线派生的 6-8 GHz 带通、5 GHz 带阻和高边阻带特征为主；S11/S22 只作为低权重辅助项参与训练。

原论文像素空间为 13x13，本项目为 16x16，二值变量从 169 增至 256。直接 flatten + MLP 不适合作为主模型，因为它没有像素邻接、局部 stub、横向通道和端口边缘耦合的先验。当前实现采用小型 CNN：3x3 局部卷积、depthwise separable residual block、一个 dilation=2 block、x/y 坐标通道和全局池化 head。这样参数量较小，适合当前小样本阶段；等 R3/R4 样本增加后再考虑更深模型。

5. 如果 R4 仍无法把 5G 明显推向 -20 dB，应新建 via-aware/shorted-stub 架构族，而不是继续增加普通悬浮像素数量。

## 25. 当前最佳模型与下一轮循环

截至 2026-08-02，当前数据集规模已更新为 145 个样本，神经网络输入为双通道：金属 mask + via 直径归一化通道，并附加 5 个几何标量。训练已从 S21-only 升级为 S11/S21/S22 三通道曲线模型；其中 S21 是主反馈，S11/S22 仅以低权重辅助训练，当前 loss 权重为 `S11:S21:S22 = 0.1:1.0:0.1`。
