## 1. 当前项目结论

当前 FR4 7 阶交指/梳状结构的最好综合候选仍是同一组几何参数：

```text
i7_fr4_r1_l555_taper
i7_fr4_r3_base
i7_fr4_r4_base
i7_fr4_r5_base
```

该候选在家里 ADS 环境、`BFP_lib:substrate4` 层叠下的 RFPro FEM 指标为：

| 指标 | 结果 | 判断 |
|---|---:|---|
| `S21@5G` | `-27.15 dB` | 满足 `<= -25 dB` |
| `S21@6G` | `-2.13 dB` | 满足 `>= -5 dB` |
| `S21@8G` | `-4.28 dB` | 满足 `>= -5 dB`，但接近边界 |
| `worst S11, 6-8G` | `-5.55 dB` | 接近 `-6 dB`，未达更高匹配目标 |
| `worst S22, 6-8G` | `-5.98 dB` | 接近 `-6 dB` |
| 通带 ripple | `2.83 dB` | 可接受 |

回波最差频点集中在 `8 GHz`：

| 候选 | `worst S11` | 频点 | `worst S22` | 频点 |
|---|---:|---:|---:|---:|
| `i7_fr4_r5_base` | `-5.55 dB` | `8.0 GHz` | `-5.98 dB` | `8.0 GHz` |

因此当前的主要问题不是 ADS 环境变量、端口线长或 50 Ω 主线宽，而是高频通带边缘的外部耦合/谐振器耦合没有完全匹配。

### 2.1 外部耦合不是越强越好

`devices/FR4高低阻抗带通滤波器优化TODO.md` 中已有失败经验：把馈电间隙压到 `0.1524 mm` 工艺下限后，8 GHz 反而明显恶化，高边抑制增强。这说明：

```text
增强外部耦合只能改变能量注入方式，不能自动保证宽带通带打开；
过强外部耦合可能引入寄生直通、额外反射或把某个带边推坏。
```

迁移到当前交指结构：

```text
feed_tip_w_mm / feed_overlap_mm 只能小步扫。
不能因为 tw020 的 S11 有改善趋势，就继续盲目加大 tip 或 overlap。
```

### 2.2 文章结构的核心是可独立调 Qe、主耦合、交叉耦合和 TZ

`6G宽带带通滤波器文章分析报告.html` 里对原文版图的细读指出，文章方案不是简单的“四腔滤波器”，而是：

```text
折叠 SIR + 双模加载 + 交叉耦合 + 混合电磁耦合
```

其中：

| 参数类别 | 控制对象 | 对当前工程的启发 |
|---|---|---|
| `t1` / feed gap | 外部品质因素 `Qe` | 当前交指的 `tap/tip/overlap/taper` 本质也是在调 `Qe` |
| 主耦合 gap | 通带带宽和极点展开 | 当前 `S1-S6` 不能只看单点 S21，要看 6-8 GHz 全带形状 |
| `d1/d2` 类局部加载 | 传输零点位置 | 当前交指没有足够独立的 TZ 控制旋钮，靠 L/gap 会互相牵制 |
| 左右镜像 | `S11/S22` 对称性 | 当前左右结果接近，说明生成器对称性基本成立 |

迁移到当前交指结构：如果只扫 `L/tap/S1/S6`，很容易出现“5 GHz 抑制、8 GHz 边缘、S11/S22 三者互相交换”的情况。要想继续冲 `-10 dB` 回波，可能需要新增更独立的端口过渡或外部耦合结构，而不仅是微调现有参数。

### 2.3 通带内深零点/局部驻波会让回波与插损同时变差

`devices/FR4折叠SIR带通滤波器分支.md` 多轮结论显示，某些结构能把一个带边打开，但会把另一个传输零点推入 6-8 GHz。典型现象是：

```text
高边零点外推后，低边零点进入 6.2-6.5 GHz；
6 GHz 与 8 GHz 难以同时保持；
继续小步 feed_tip/feed_overlap 的收益有限。
```

迁移到当前交指结构：当前 7 阶交指没有出现 folded SIR 那种通带中部几十 dB 深陷波，但 `8 GHz` 同时是 `S21` 最弱点和 `S11/S22` 最差点，说明高边已经存在局部驻波/极点覆盖不足的问题。优化评分必须同时看：

```text
S21@6G
S21@8G
worst S11/S22
passband ripple
传输峰/谷频点
```

不能只看 `S21@5G` 是否够深。

### 2.4 9 阶交指经验：抑制达标和回波达标不是同一个旋钮

`SIM-83_plus_滤波器优化验证报告.html` 中 9 阶 RO4350 交指分支已经出现类似矛盾：

| 候选 | 有利点 | 问题 |
|---|---|---|
| `r3_t187` | `5 GHz` 抑制可达约 `-45 dB` | 回波只有约 `-3 dB` |
| `r3_e540` | 回波可改善到约 `-8 dB` | `5 GHz` 抑制不足 |
| `r2e_l600` | 综合较可信 | `S11/S22` 仍约 `-5.4 dB` |

迁移到当前 FR4 7 阶结构：现在的 `base` 与 `tw020` 也是同类折中：

```text
base  : 5 GHz 抑制够，S22 较好，但 8 GHz/S11 边界。
tw020 : 8 GHz/S11 改善，但 5 GHz 抑制差 0.03 dB。
```

因此下一轮应该做“守住 5 GHz 的匹配补偿”，不是重新扫一组无方向的大参数。

## 3. 交指滤波器的基本结构

交指带通滤波器通常由多根约 `lambda_g/4` 的短路谐振器组成，相邻谐振器的短路端交替布置，通过边缘电磁耦合形成带通响应。输入和输出端口通过抽头、间隙耦合、锥形过渡或直接搭接等方式与首末谐振器耦合。

对当前版图而言，可以把它理解成三个层级：

| 层级 | 对应参数 | 主要影响 |
|---|---|---|
| 谐振器本体 | `L_mm`, `Egap_mm`, via 位置/孔径 | 中心频率、低边/高边位置、端部加载 |
| 谐振器间耦合 | `S1_mm` 到 `S6_mm` | 带宽、通带 ripple、边缘插损、传输零点趋势 |
| 端口外部耦合 | `tap_mm`, `feed_tip_w_mm`, `feed_overlap_mm`, `feed_taper_len_mm` | `Qe`、`S11/S22`、通带边缘能量注入 |

## 4. 回波损耗的定义

S 参数中：

```text
S11_dB = 20 log10(|S11|)
S22_dB = 20 log10(|S22|)
RL11   = -20 log10(|S11|)
RL22   = -20 log10(|S22|)
```

ADS/RFPro CSV 中的 `s11_db` 是负数。工程口径中说“回波损耗 10 dB”，通常等价于：

```text
S11_dB <= -10 dB
```

反射系数与输入阻抗关系为：

```text
Gamma = (Zin - Z0) / (Zin + Z0)
```

所以 `S11` 变差，本质是滤波器在该频点呈现给端口的等效输入阻抗偏离 `50 ohm`。

## 5. Chebyshev ripple 与理论回波下限

理想无耗滤波器中，通带内有：

```text
|S11|^2 + |S21|^2 = 1
```

若 Chebyshev 通带 ripple 为 `LAr dB`，通带最差传输幅度平方为：

```text
|S21|min^2 = 10^(-LAr / 10)
```

对应最大反射系数为：

```text
|Gamma|max = sqrt(1 - 10^(-LAr / 10))
```

对应最小回波损耗为：

```text
RLmin = -20 log10(|Gamma|max)
```

例：若理论 ripple 取 `0.1 dB`，则：

```text
|Gamma|max ~= 0.151
RLmin ~= 16.4 dB
S11_dB ~= -16.4 dB
```

当前 FEM 只有约 `-5.5 dB` 到 `-6.0 dB`，说明问题不是 Chebyshev 原型 ripple 本身，而是实际版图的外部 Q、耦合系数、损耗、过孔寄生、端口过渡和材料离散已经明显偏离理想综合值。

## 6. 外部品质因数 Qe

交指滤波器的输入/输出匹配首先由外部品质因数 `Qe` 控制。`Qe` 描述端口向首末谐振器注入能量的强弱。

对窄带耦合谐振器滤波器，低通原型到带通的常用关系为：

```text
FBW = (f2 - f1) / f0
f0  = sqrt(f1 * f2)

Qe1 = g0 * g1 / FBW
Qen = gn * g(n+1) / FBW
Mij = FBW / sqrt(gi * gj)
```

其中：

| 符号 | 含义 |
|---|---|
| `f1`, `f2` | 通带下、上边频率 |
| `f0` | 几何中心频率 |
| `FBW` | 分数带宽 |
| `g0...g(n+1)` | 低通原型参数 |
| `Qe1`, `Qen` | 输入/输出外部品质因数 |
| `Mij` | 相邻谐振器归一化耦合 |

对于当前 6-8 GHz 目标：

```text
f0  = sqrt(6 * 8) = 6.928 GHz
FBW = (8 - 6) / 6.928 = 0.289
```

这个带宽并不窄，FR4 损耗又高，因此交指结构的外部耦合容差会比较紧。`Qe` 稍微偏大，8 GHz 边缘容易进不去；`Qe` 稍微偏小，低边阻带又可能泄漏。

## 7. Qe 的提取方法

文献和工程设计中常用单谐振器仿真提取 `Qe`，而不是直接在完整滤波器里盲扫。

反射群时延法常用表达为：

```text
Qe = omega0 * tau(f0) / 4
omega0 = 2 * pi * f0
```

等价写法：

```text
Qe = 2 * pi * f0 * tau(f0) / 4
```

其中 `tau(f0)` 是单端口激励下，谐振频率处的反射群时延。

工程含义：

| 现象 | 说明 |
|---|---|
| `Qe` 过大 | 外部耦合太弱，通带边缘插损变差，能量进不去 |
| `Qe` 过小 | 外部耦合太强，可能低边泄漏、通带 ripple 增大、回波变差 |
| 输入 `Qe1` 与输出 `Qen` 不一致 | `S11/S22` 不对称，左右端口匹配不同 |

## 8. 谐振器间耦合系数

相邻谐振器的耦合系数可通过双谐振器奇偶模或频率分裂法提取：

```text
k = (f2^2 - f1^2) / (f2^2 + f1^2)
```

其中 `f1`、`f2` 是两个耦合谐振器产生的分裂谐振频率。

工程含义：

| 参数 | 增大间隙时 | 减小间隙时 |
|---|---|---|
| `S1/S6` 外侧耦合 | 首末级耦合变弱，高边/低边可能塌陷 | 外侧耦合变强，通带可能变宽，但阻带泄漏和 ripple 可能变差 |
| `S2/S5` 次外侧耦合 | 带宽收窄，边缘插损变差 | 带宽变宽，可能降低边缘插损 |
| `S3/S4` 中心耦合 | 中心通带形状变化，ripple 变化 | 中心耦合增强，通带峰谷位置变化 |

当前 round4 中单独放宽或收紧 `S1/S6` 没有让 `S11/S22` 同时改善，说明问题不只是某一个外侧 gap，而是外部 Q 与高边耦合整体还没对齐。

## 9. 影响 S11/S22 的主要版图因素

### 8.1 抽头位置 tap

`tap_mm` 决定端口接入谐振器的等效阻抗位置。

通常趋势：

| tap 变化 | 可能结果 |
|---|---|
| 抽头更靠近短路端 | 接入阻抗更低，外部耦合形态改变，可能欠耦合或局部不连续增强 |
| 抽头更靠近开路端 | 接入阻抗更高，端口加载更强，可能过耦合 |

当前 round3 中 `tap=1.94/1.96` 的小步变化没有改善回波，说明最佳点附近较平坦，或者当前的主要限制不在单独 tap。

### 8.2 feed_tip_w

`feed_tip_w_mm` 是当前锥形过渡末端和谐振器局部接入处的有效宽度，直接改变局部电容、电流扩散和外部耦合强度。

当前结果很有价值：

| 候选 | `feed_tip_w` | `S21@5G` | `S21@8G` | `S11/S22` |
|---|---:|---:|---:|---:|
| base | `0.18 mm` | `-27.15 dB` | `-4.28 dB` | `-5.55 / -5.98 dB` |
| `tw020` | `0.20 mm` | `-24.97 dB` | `-4.03 dB` | `-5.68 / -5.64 dB` |

判断：

```text
tip_w 从 0.18 增大到 0.20 mm 后，高边 8 GHz 和 S11 有改善趋势；
但 5 GHz 抑制损失约 2.18 dB，刚好越过 -25 dB 门限。
```

这说明 `tip_w=0.20` 是下一轮最值得保留的方向，但必须配合 `L/Egap/S1/S6` 把低边阻带拉回来。

### 8.3 feed_overlap

`feed_overlap_mm` 改变馈线锥形尖端进入首末谐振器区域的程度。

| overlap 变化 | 可能结果 |
|---|---|
| 增大 | 外部耦合增强，8 GHz 边缘可能改善，但低边阻带可能变差 |
| 减小 | 低边阻带可能改善，但通带边缘和回波可能变差 |

当前 round3 的 `overlap=0.08` 提高了 8 GHz，但 `5G=-23.44 dB`，低边泄漏太大。因此 overlap 不宜继续大幅增加。

### 8.4 feed_taper_len

`feed_taper_len_mm` 主要改变 50 Ω 线到局部耦合点的阻抗过渡。

当前结果显示：

| 变化 | 结果 |
|---|---|
| `0.45 mm` | 仍可用，但回波不优 |
| `0.75 mm` | 响应明显恶化 |

判断：当前 `0.60 mm` 是较稳值。继续把 taper 拉长不是主要方向。

### 8.5 50 Ω 主线宽 W0

`W0` 理论上应由家里层叠 `FR4 h=0.210 mm, Er=4.6, Cu=35 um` 决定。当前基准 `W0=0.3648 mm` 是 50 Ω 线宽近似。

round5 已验证：

```text
W0 = 0.335 / 0.345 / 0.385 / 0.405 mm
```

均未改善综合匹配。结论是：不应通过偏离 50 Ω 主线来修回波，这会把端口参考也一起扰乱。

### 8.6 端部间隙 Egap

`Egap_mm` 改变开路端边缘电容和奇偶模频率，因此会影响带边位置和传输零点。

趋势：

| Egap 变化 | 可能结果 |
|---|---|
| 增大 | 端部电容减弱，等效电长度下降，频率可能上移 |
| 减小 | 端部加载增强，等效电长度增加，频率可能下移 |

实际方向必须靠 FEM 验证，因为交指结构里端部电容、相邻耦合和 via 寄生会叠加。

### 8.7 接地过孔和短路端寄生

交指/梳状结构依赖短路端接地。过孔不是理想短路，存在寄生电感。

影响包括：

| 因素 | 对回波的影响 |
|---|---|
| via 直径 | 孔太小，接地电感上升，短路端偏离理想 |
| via pad | 焊盘改变局部电容和电流扩散 |
| via 位置 | 偏离短路端会改变等效电长度 |
| via 到地平面连接 | 连接差会让谐振器短路条件失真 |

当前家里层叠使用 `pcvia1_d0p254mm`，钻孔 `0.254 mm`，顶层 pad `0.3556 mm`。这套值已满足工艺，但后续如果追求 `S11/S22 <= -10 dB`，via 模型和接地返回路径需要复核。

## 11. 当前优化方向判断

根据 round2 到 round5 的结果，变量有效性排序如下：

| 变量 | 当前判断 | 下一步建议 |
|---|---|---|
| `feed_tip_w_mm` | 有改善 8 GHz 和 S11 的趋势 | 重点扫 `0.195 / 0.200 / 0.205` |
| `L_mm` | 能补偿低边阻带和整体频偏 | 配合 `tip_w=0.20` 小步扫 `5.535-5.550` |
| `Egap_mm` | 可能细调带边和端部加载 | 小步扫，不大改 |
| `S1/S6` | 单独扫效果不佳 | 只与 `tip_w/L` 组合微调 |
| `tap_mm` | 单独小步效果不明显 | 保留 `1.95` 附近微调 |
| `W0_mm` | round5 已证明综合变差 | 不建议继续扫 |
| `feed_len_mm` | round5 已证明综合变差 | 不建议继续扫 |
| `feed_taper_len_mm` | `0.60 mm` 较稳，`0.75 mm` 变差 | 暂不作为主变量 |
| `feed_overlap_mm` | 增大容易损失 5 GHz 阻带 | 不建议大幅增加 |

下一轮更合理的候选中心是：

```text
seed: i7_fr4_r3_t195_tw020
原因: 8 GHz 与 S11 趋势更好，只差 5 GHz 抑制 0.03 dB
```

建议组合：

```text
feed_tip_w_mm = 0.195 / 0.200 / 0.205
L_mm          = 5.535 / 5.540 / 5.545 / 5.550
Egap_mm       = 0.4723 / 0.4823 / 0.4923
S1/S6         = 0.1126 / 0.1176 / 0.1226
tap_mm        = 1.945 / 1.950 / 1.955
```

初轮不要做全因子组合，建议 12-18 个候选即可：

```text
1. base repeat
2. tw020 repeat
3. tw0195
```

## 12. 推荐建立的提取流程

为了减少盲扫，建议新增两个辅助仿真流程。

### 11.1 单谐振器 Qe 提取

目标：固定家里 `BFP_lib:substrate4`，只保留首个谐振器和输入馈线，扫描：

```text
tap_mm
feed_tip_w_mm
feed_overlap_mm
feed_taper_len_mm
```

输出：

```text
candidate, f0_ghz, group_delay_ns, Qe, notes
```

用途：

```text
先找到外部 Qe 接近设计值的馈入结构，再放回完整 7 阶滤波器。
```

### 11.2 双谐振器 k 提取

目标：分别保留两根相邻谐振器，扫描：

```text
S1/S6
S2/S5
S3/S4
```

输出：

```text
pair, gap_mm, f1_ghz, f2_ghz, k
```

用途：

```text
把 gap 与耦合系数建立查找表，避免完整滤波器里只靠经验猜。
```

## 14. 对当前工程的直接结论

当前 `S11/S22` 不够深，不应理解为“端口线没拉够长”或“ADS 端口错了”。因为：

```text
1. 家里 ADS profile、BFP_lib、substrate4、FR4 210 um 层叠已经验证。
2. round5 改 W0/feed_len 后综合回波变差，说明偏离 50 Ω 主线不是正解。
3. 最差回波在 8 GHz，且 S21@8G 也是通带最弱点，说明高边外部耦合/谐振器耦合不足。
4. tip_w=0.20 已经把 8 GHz 和 S11 往正确方向推，但低边 5 GHz 抑制被抬高。
```

下一步应以 `tw020` 为种子做小步补偿：

```text
保留 feed_tip_w_mm ~= 0.20
略缩短 L 或微调 Egap，补回 5 GHz 抑制
只小步联动 S1/S6 和 tap
不再优先扫 W0/feed_len
```
