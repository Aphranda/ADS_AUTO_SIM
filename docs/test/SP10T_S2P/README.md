# SP10T_S2P 实测数据说明（3 × HMC7992 SP4T 组成 SP10T）

Status: Active
Domain: TEST
Date: 2026-08-21
Location: `docs/test/SP10T_S2P/`

## 1. 数据来源与测量条件

- 仪器：Agilent N5230C（A.09.42.22），全二端口校准（S11/S21/S12/S22）
- 文件格式：Touchstone S2P，`# Hz S dB R 50`（幅度列即为 dB）
- 扫频：10 MHz – 10 GHz，201 点（开关额定 6 GHz，10 GHz 为超规格延伸）
- 端口定义：VNA 端口 1 → SP10T 公共端 RFC；VNA 端口 2 → 被选通的 RF 端口
- 板级：FR4 走线约 100 mm；各 RF 通路串联 ~100 pF 级隔直电容
  （10 MHz 处 S21 ≈ −11 dB 的滚降即隔直电容所致，与 HMC7992 需外接
  隔直电容的 datasheet 要求一致）

## 2. 器件与组网

HMC7992 为 **SP4T**（非反射硅开关，0.1–6 GHz，内置 2:4 译码器，A/B 控制）：

| A | B | 导通路径 |
|---|---|---|
| 低 | 低 | RF1 |
| 高 | 低 | RF2 |
| 低 | 高 | RF3 |
| 高 | 高 | RF4 |

3 个 HMC7992 树形两级组成 SP10T：

```
RFC ── SP4T#1 ──┬── Branch A ── SP4T#2 ── RF1 ~ RF4
                ├── Branch B ── SP4T#3 ── RF5 ~ RF8
                ├── Branch C ── RF9（直出）
                └── Branch D ── RF10（直出）
```

- 文件编号 = RF 端口号：`1.s2p`=RF1，…，`10.s2p`=RF10（用户确认）
- `78.s2p` 为 RF7↔RF8 二级开关通路典型隔离度，`910.s2p` 为 RF9↔RF10 一级开关通路典型隔离度
- SP4T#1 的 4 个分支中，2 路直出（RF9/RF10），2 路接二级 SP4T（用户确认）
- SP4T#1 的 Branch A~D 与封装输出（RF1~RF4 of SP4T#1）的具体对应关系为板级信息，
  见 §6 控制真值表（待按板图填写）

## 3. 实测分组（由 S 参数直接验证）

| 组 | RF 端口 | 文件 | 0.5 GHz | 1 GHz | 2 GHz | 4 GHz | 6 GHz | 群延时@1GHz | 通路结构 |
|---|---|---|---|---|---|---|---|---|---|
| C | RF9, RF10 | 9.s2p, 10.s2p | −0.9 | −1.1 | −1.5 | −2.1 | −2.9 | ≈ 470 ps | 1 级开关（直出） |
| B | RF2, RF3, RF6, RF7 | 2,3,6,7.s2p | −1.71 | −1.97 | −2.6 | −3.7 | −4.9 | ≈ 666 ps | 2 级开关（短支路） |
| A | RF1, RF4, RF5, RF8 | 1,4,5,8.s2p | −1.77 | −2.10 | −3.0 | −4.2 | −5.3 | ≈ 770 ps | 2 级开关（长支路） |

- 组 C（RF9/RF10）只过 1 级开关：插损最低，且两文件几乎一致（相位差仅 4 ps）
- 组 A/B 多一级开关：插损高约 0.8–1.0 dB（2 GHz 处）
- 组 A 比组 B 多 ≈105 ps ≈ 17 mm 等效走线；组内规律 {1,4}、{2,3}、{5,8}、{6,7}
  成对 → 疑似 HMC7992 封装两侧引脚（RF1/RF4 一侧、RF2/RF3 一侧）板上出线长度不同，
  两个二级 SP4T 同向摆放所致

## 4. 典型端口隔离度

隔离度文件采用二端口双向测量。报告按 `Isolation = -max(S21, S12)` 取两方向中较差值，
避免仅选较好方向造成高估。

| 通路结构 | 端口对 | 文件 | 6 GHz | 8 GHz | 0.5–6 GHz 最低值 | 7–8 GHz 最低值 |
|---|---|---|---:|---:|---:|---:|
| 二级开关典型 | RF7↔RF8 | `78.s2p` | 39.5 dB | 37.7 dB | 39.3 dB @ 5.904 GHz | 37.9 dB @ 7.952 GHz |
| 一级开关典型 | RF9↔RF10 | `910.s2p` | 41.4 dB | 35.7 dB | 41.6 dB @ 5.954 GHz | 36.0 dB @ 7.952 GHz |

以上为两个典型端口对的板级实测结果，不代表完整 10×10 端口隔离矩阵，也不直接等同于
HMC7992 数据手册中的 RFC-to-RF 器件级隔离度。

## 5. 走线长度估算（FR4，εeff ≈ 3.5，160 mm/ns）

| 对比 | 延时差 | 等效长度差 |
|---|---|---|
| 组A − 组C | +300 ps | ≈ +48 mm |
| 组B − 组C | +194 ps | ≈ +31 mm |
| 组A − 组B | +105 ps | ≈ +17 mm |

各组总等效 FR4 长度（含开关内部延时与连接器）：组C ≈ 75 mm、组B ≈ 107 mm、
组A ≈ 123 mm。各文件共用 RFC 侧路径，组间差异可靠；纯走线长度需扣除开关/连接器部分。

## 6. 各状态控制真值表（待填 SP4T#1 分支分配）

HMC7992 A/B 位：`0`=低，`1`=高。二级开关未参与的通路可任意（don't care）。

| SP10T 状态 | SP4T#1 所需选通 | SP4T#2 (A2,B2) | SP4T#3 (A3,B3) |
|---|---|---|---|
| RF1 | Branch A（A1,B1 = ?） | (0,0) | 任意 |
| RF2 | Branch A | (1,0) | 任意 |
| RF3 | Branch A | (0,1) | 任意 |
| RF4 | Branch A | (1,1) | 任意 |
| RF5 | Branch B（A1,B1 = ?） | 任意 | (0,0) |
| RF6 | Branch B | 任意 | (1,0) |
| RF7 | Branch B | 任意 | (0,1) |
| RF8 | Branch B | 任意 | (1,1) |
| RF9 | Branch C（A1,B1 = ?） | 任意 | 任意 |
| RF10 | Branch D（A1,B1 = ?） | 任意 | 任意 |

> SP4T#1 的 A1/B1 组合与 Branch A~D 的对应取决于板图接线，按板图填写后即完整。
