1. 设计结论
方案可行，但当前仍是工程样机级状态。 RO4350B 0.508 mm 层叠下，九阶交指结构可以把 5 GHz 抑制推到约 45 dB， 已接近频率规划提出的最低边界。当前最可信、综合最好候选为 r3b_t190， 因为它已经由 ADS EM Setup fitted 数据复核，且 5 GHz、6 GHz、8 GHz 三个关键频点均接近目标边界。
主要风险集中在通带边缘和匹配。 r3b_t190 的 6 GHz 插损约 -3.44 dB、8 GHz 插损约 -3.00 dB， S11/S22 最差仅约 -5.4 dB。若最终规格要求 S11/S22 ≤ -10 dB， 需要继续优化端口过渡与首末谐振器耦合。
建议判据：5 GHz 抑制若只按链路余量最低要求，-45 dB 可作为边界值；若要留加工、介电常数、铜厚和装配偏差余量，建议设计目标提高到 -50 dB 左右。

6. 闭环流程
1 参数生成由 CSV 定义 L、tap、Egap、S1/S8 等变量。
2 生成 DXFPython 输出 mm 坐标 DXF、SVG、DRC 和参数表。
3 导入 ADSADS Python 导入 DXF，将线框转为 shape，补充圆孔。
4 放置端口自动放置 P1/P2，端口位置保持与馈线一致。
5 克隆 EM setup复用模板，修改仿真频段为 4-10 GHz。
6 运行 FEM稳定路径通过 RFPro Analysis API 触发仿真。
7 导出结果导出 S11/S21/S22 CSV，或读取 FEM_a.ds fitted 数据。
8 自动评分计算 5G 抑制、6/8G 插损、通带最差、ripple、回波。
7. 脚本分工
脚本作用当前用途
SIM\tools\generate_interdigital_filter_layout.py根据参数生成交指滤波器 DXF/SVG/DRC。候选版图生成。
SIM\tools\make_filter_round3_l600_candidates.py围绕 r2e_l600 生成第三轮候选参数表。第三轮优化输入。
SIM\tools\ads_import_dxf_add_ports.py在 ADS 中导入 DXF、转 shape、补圆孔和 P1/P2 端口。版图入库自动化。
SIM\tools\run_ads_filter_candidate.py单候选完整流程：导入、setup、仿真、导出、评分。烟雾测试和单点复核。
SIM\tools\run_ads_filter_sweep.py按候选表批量运行，并生成 sweep_summary.csv。批量趋势筛选。
SIM\tools\export_ads_fem_dataset.py读取 ADS EM Setup 生成的 *_FEM_a.ds fitted 数据并导出 TXT/CSV。Data Display 结果复核。
8. 稳定运行命令
python SIM\tools\run_ads_filter_sweep.py --plan SIM\ADS\filter_opt_round3_l600.csv --out-dir SIM\ADS\opt_round3_l600 --results-dir SIM\ADS\results\opt_round3_l600 --summary SIM\ADS\results\opt_round3_l600\sweep_summary.csv --skip-generate --continue-on-error
推荐稳定路线
  • 使用 RFPro API 批量跑候选，快速判断参数趋势。
  • 每轮先跑 1 个 smoke candidate，确认 ADS 会话、路径和端口无异常。
  • 通过 sweep_summary.csv 排序后，只选少量候选进入 EM Setup fitted 复核。
暂不建议的路线
  • 直接模拟 GUI 点击 EM Setup 的 Simulate 按钮，目前未找到稳定公开 API。
  • oa-emdata 结果动作曾出现挂起/残留进程，暂不作为主流程。
  • 多候选长批量前不做 smoke test，容易因单点异常卡住整轮。

10. 推荐下一轮候选
优先级候选/方向目的判据
P1r3b_t190作为 EM Setup fitted 复测后的综合最佳基准。后续优化优先保持其 6/8 GHz 边缘，再改善匹配。
参考r3b_l598 / r3b_l599证明缩短 L 可以加深 5 GHz 抑制。不建议直接作为主点，因为通带边缘损失过大。

P3r3_e540 方向保留其匹配改善迹象，复核是否真实。若 EM fitted 可复现，可扩展为匹配优化支路。
